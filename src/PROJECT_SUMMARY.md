## 🎨 Design System Highlights

### Spacing (8pt Grid)
| Token | Size | Primary Use |
|-------|------|-------------|
| spacing-2 | 8px | Base unit |
| spacing-4 | 16px | Form fields, filters |
| **spacing-6** | **24px** | **Section gaps (PRIMARY)** |
| spacing-8 | 32px | Large gaps |
| spacing-12 | 48px | Icon containers |

### Typography
| Token | Size | Weight | Use Case |
|-------|------|--------|----------|
| **display-s** | **24px** | Bold | **Page titles** |
| headline-l | 30px | Bold | KPI values |
| subtitle-s | 16px | Semibold | Card titles |
| **body-m** | **14px** | Regular | **Body text (PRIMARY)** |
| caption | 12px | Regular | Metadata |

### Icon Sizes
| Size | Tailwind | Use Case |

| 32px | h-8 w-8 | Empty states |
